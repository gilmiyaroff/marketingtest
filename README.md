# CAP Growth Quest — Marketing Quest v6

Интерактивная игровая презентация маркетинговой стратегии развития CAP Education и запуска нового продукта по школьным предметам.

## Сценарий
Пять связанных игровых миссий:
1. **Исследование** — изучаем целевые сегменты, рынок и обратную связь первых пользователей.
2. **Стратегия** — собираем архитектуру маркетингового плана: аудитория, позиционирование, пилот, каналы, KPI.
3. **Пилот** — разбираем пользовательский путь, точки потерь и гипотезы улучшения.
4. **Контент и рост** — соединяем Shorts/Reels, родительские UGC, бесплатную диагностику и рекомендации с задачами воронки.
5. **Экономика** — настраиваем конверсию, retention и партнёрские вознаграждения.

В финале — конкретный предварительный план на первые 90 дней работы маркетинга, а не обещания выручки без данных.

## Файлы
- `index.html` — вся игровая логика, HTML, CSS и SVG-иконки.
- `assets/scenes/*.webp` — шесть игровых локаций с адаптивным кадрированием.
- `assets/characters/hero-petting.webp` — анимированные мальчик и кот, прозрачный фон.
- `assets/characters/hero-petting.gif` — резервный формат анимации.
- `archive/cap-growth-quest-v5-2026-11-11.html` — исходная версия v5.

## Адаптация экранов
Фоны используют `object-fit: cover` и индивидуальные `object-position`; декоративные и интерактивные элементы — отдельные SVG/HTML-слои. В студии контента широкий экран выделяет область стола и ноутбука.

## Типографика
- Press Start 2P — короткие игровые заголовки;
- Tektur — описание задач, диалоги, кнопки и показатели.

## Запуск
GitHub Pages: ветка `main`, папка `/ (root)`, затем открыть https://gilmiyaroff.github.io/marketingtest/

Для локального просмотра достаточно открыть `index.html`, без сборщиков или сервера.

> Презентация демонстрирует гипотезы маркетингового роста, а не гарантированные показатели бизнеса. Числовые показатели пилота и симулятора условные. Реферальные программы и реклама с участием несовершеннолетних требуют юридической проверки.
