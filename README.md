# CAP Growth Quest — Pixel Edition v3

Игровая презентация стратегии запуска массового образовательного продукта CAP Education, адаптированная под вертикальный экран телефона.

## Содержимое

- `index.html` — вход в игру, движок мини-игр, интерфейс, финальная стратегия на 90 дней (чистые HTML/CSS/JS).
- `assets/img/hero.webp` — пиксельная стартовая сцена, ранее созданная для проекта.
- `assets/img/study.webp` — панорама класса для поиска объектов.
- `assets/img/monitor.webp` — крупный план компьютера для головоломки.
- `assets/ui/*.svg` — вспомогательные иконки и пиксельные рамки.
- `archive/cap-growth-quest-v2.html` — сохранённая предыдущая версия (только в GitHub).

## Сценарий

1. **Главное меню:** иллюстрированная вертикальная заставка, интерактивные области кнопок, анимация приближения к ноутбуку.
2. **Миссия 1 — поиск:** горизонтально прокручиваемая панорама, три подсказки (глобус, тетрадь, компьютер) и смысловые объяснения.
3. **Миссия 2 — конструктор:** 5 блоков учебного маршрута, перетаскивание на ПК и касания на телефоне, проверка последовательности.
4. **Миссия 3 — соединения:** сопоставление маркетинговых инструментов с целевыми результатами, SVG-линии.
5. **Финал:** концепция стратегии запуска на 90 дней и ключевой принцип продукта.

## Как запускать

Откройте `index.html` — сборка и сервер не нужны. Для GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

Ожидаемый адрес: https://gilmiyaroff.github.io/marketingtest/

## UX

- Рассчитано на портретный телефон и десктоп с игровым окном.
- Для drag-and-drop предусмотрено управление нажатием: сначала карточка, потом слот.
- Звук выключен по умолчанию; короткие оригинальные звуки синтезируются Web Audio API.
- Прогресс сохраняется в `sessionStorage` текущей вкладки.
- `prefers-reduced-motion` снижает анимации.

## Ограничения

Это концептуальная презентация, а не действующий сервис и не утверждённая стратегия CAP Education. Метрики не используются как реальные показатели компании. Для программ с детьми и партнерских выплат требуется отдельная юридическая оценка.
