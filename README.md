# CAP Growth Quest 2.0

Интерактивная игровая презентация стратегии запуска школьного EdTech-продукта для CAP Education.

## Играть

Откройте `index.html` в браузере или опубликуйте сайт через GitHub Pages.

## Миссии

1. **Найти проблему:** обнаружить три скрытые подсказки в школьном классе.
2. **Собрать учебный маршрут:** расставить блоки диагностики, объяснения, практики и прогресса.
3. **Соединить маркетинговые инструменты:** провести линии между контентными механиками и результатами.
4. **Распределить рекомендации:** система игровых монет для учеников и партнёрские выплаты для родителей.
5. **Сбалансировать экономику:** настроить параметры реферальной программы и получить план на 90 дней.

## Технологии

Чистые HTML, CSS, JavaScript и SVG. Без сборки, сервера, внешних библиотек и API. Адаптивный интерфейс для компьютеров и телефонов.

## GitHub Pages

В репозитории откройте **Settings → Pages → Build and deployment** и выберите:

- **Source:** Deploy from a branch
- **Branch:** `main`
- **Folder:** `/ (root)`
